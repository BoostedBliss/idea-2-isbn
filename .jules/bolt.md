## 2025-02-23 - Extracted Reusable BSR Daily Sales Calculator
**Learning:** The React `useMemo` hooks `estimatedSales`, `projectionData`, and `proProjectionData` inside `src/App.tsx` were duplicating a massive `if-else` statement to map BSR limits to expected daily sales. This resulted in redundant evaluations for every item in 30-day projection lists whenever states like target BSR updated. This codebase-specific pattern of identical mapping operations across multiple UI state views causes severe repetition.
**Action:** Always extract shared mapping logic (like data conversion from range to integer limits) into a pure function external to the React component (e.g., `getDailySalesForBsr`), which guarantees it's only instantiated once and reduces block redundancy inside hooks.
